DIĒTA — personīgā uztura aplikācija

Kas iekšā:
- Dienas kalorijas, OB, tauki, OH, šķiedrvielas
- Tavi sākotnējie mērķi: 2100 kcal, 156 g OB, 47 g tauku, 263 g OH, 30 g šķiedrvielu
- Biežāk lietotie produkti jau datubāzē
- Var pievienot savus produktus pēc etiķetes
- 7 dienu vidējie
- Dati glabājas lokāli ierīcē

Kā palaist:
1. Ieliec failus uz jebkura vienkārša HTTPS hostinga (piem. GitHub Pages / Netlify / Vercel).
2. Atver Safari iPhone.
3. Share → Add to Home Screen.
4. Aplikācija darbosies kā PWA.

Svarīgi:
- Ja atver index.html vienkārši kā failu, pamata funkcijas strādās, bet PWA instalēšana/service worker parasti prasa HTTPS.
- Dati netiek sinhronizēti starp ierīcēm, jo šī ir privāta lokāla versija.
